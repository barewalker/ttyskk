# 文脈で候補が変わるか試す

各節の中に「▶」の行がある。その行末で挿入モードに入り、Kousei または Kouen と打って
space を押す。答えの漢字はこの文書のどこにも書いていないので、当たれば注釈の共起語が
効いたことになる。

**端末の ttyskk で打つこと。** fcitx5 側が有効だとそちらが入力を取ってしまい、画面の
文脈は一切使われない。GUI の入力メソッドを切ってから試す。


## 一 新聞社の作業

けさ届いた新聞をひろげて、社会面の記事にざっと目をとおした。日付のまちがいが二か所、
人名のよみがなのぬけが一か所あった。締切におわれていたのだろう。組版にまわす前に、
もういちど朱を入れておく必要がある。担当のデスクにその旨をつたえた。紙面はいちど
刷ってしまえば直せない。だからこの工程だけは、どれだけ急いでいても省いてはいけない。

▶ ここで Kousei と打って space

記者からあがってきた原稿は、まず用字用語の統一からはじめる。数字の全角と半角、
送りがなの ゆれ、外来語のながさ。そういう細かいところに、読者はよく気がつく。

きのうは雨がふっていたが、けさになってようやくやんだ。空はまだ灰色のままだ。
ひるすぎには晴れるという。洗濯物を干すかどうか、まよっているところである。
