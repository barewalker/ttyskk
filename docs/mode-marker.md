# モードの見た目

いまどのモードにいるかを、カーソルのあたりで示します。何も打っていない状態でも見て判断
できます。出し方は五通りから選べます。

```toml
[behavior]
mode_marker = "cell"     # カーソルのセルに色を敷きます (既定)
mode_marker = "symbol"   # カーソルのセルに半角の記号を出します
mode_marker = "beside"   # カーソルの右隣のセルに色を敷きます
mode_marker = "letter"   # カーソルの直後に あ / ア / 半 / Ａ を出します
mode_marker = "off"      # 何も描かず、カーソルの形だけで表します
```

**`cell` と `beside` は文字を足しません。** セルの色だけを変えるので、行の長さも中身も
変わりません。違いは置く場所だけです。

| モード | 色 | `symbol` の記号 | `letter` の印 | `off` のときの形 |
|---|---|---|---|---|
| ASCII | **色を敷きません** | **記号なし** | **印なし** | 下線 |
| ひらがな | 緑 | `~` | あ | ブロック |
| カタカナ | 水色 | `+` | ア | バー |
| 半角カタカナ | 青緑 | `-` | 半 | 点滅するバー |
| 全角英数 | 紫 | `@` | Ａ | 点滅するブロック |

**ASCII モードでは何も描きません**ので、日本語を打っていないときの透過は保たれます。

子アプリがカーソルの形や色を変えた場合 (`vim` など) は、そのつど塗り直してモードの合図を
保ちます。`TTYSKK_NO_CURSOR` を設定すると、カーソルには一切触りません。

## 記号で示す (`symbol`)

**`symbol` は色に頼りません。** カーソル位置に半角一桁の記号を出すので、白黒の端末でも
モードが分かります。色も併せて付くため、色が使える環境では二重の手掛かりになります。

**記号を出すのは空きセルの上だけです。** 打ち終えた文字の上へカーソルを戻したときは、記号を
引っ込めて色だけを敷きます (`cell` と同じ姿になります)。記号で置き換えると、その一文字が読め
なくなるためです。かなを打っている間のカーソルはたいてい行末の空きセルにあるので、普段は記号
が出ていて、行の途中へ戻ったときだけ色に変わります。

記号にしてあるのは、英字だと本文と紛れるためです。既定は「ひらがなは曲線的な `~`、カタカナ
は角ばった `+`、半角カタカナは `+` から縦棒を取った `-` (半分)、全角英数は英数の `@`」という
覚え方です。好みで変えられます。

```toml
[behavior.mode_symbols]
hiragana = "#"
katakana = "*"
hankaku_katakana = "="
zenkaku = "%"
```

**半角一桁の文字だけ**を受け付けます (全角を許すと幅が二桁になり、見た目が崩れるためです)。
ASCII で使えるのは `! " # $ % & ' ( ) * + , - . / : ; < = > ? @ [ \ ] ^ _ ` { | } ~` です。
反転表示の一桁で見分けやすいのは `# * + @ % & ~ =` あたりです。

モノクロの記号も使えます。ASCII より形の差が大きいので見分けやすくなります。

```toml
[behavior.mode_symbols]
hiragana = "♪"           # 曲線的
katakana = "★"           # 角ばった塗りつぶし
hankaku_katakana = "☆"   # ★ の中抜き (半分)
zenkaku = "◆"
```

通るのは `❤ ⚠ ★ ☆ ✓ ✔ ✗ ✖ ♪ ◆ ● ▲ ☺ ❄ ✎ ➤ ✚ ☯ ☀ ☂ ♦ ◎ ⌘ ⚑ ⚙` などです。**色付きの絵文字は
使えません** —— `😀 ⭐ ✅ ☕ ⚡` のたぐいは幅が二桁になるためです。`❤️` のように異体字
セレクタ (U+FE0F) が付いたものも、二コードポイントになるので受け付けません (`❤` なら通り
ます)。

ただし `★ ☆ ◆ ● ▲ ◎ ♪ ☺` などは Unicode 上「幅が曖昧」な文字です。ttyskk は一桁と見なし
ますが、**端末やフォントの設定によっては二桁で描かれます**。その場合は印がずれるので、
切り替えて確かめてからお使いください。崩れるようなら ASCII の記号に戻すのが確実です。

## 端末多重化器を挟むとき

**多重化器を挟むと、カーソルの色 (OSC 12) も形 (DECSCUSR) も外側の端末まで届きません。**
herdr で実測したところ、ペインからどちらを指定しても外側は白い四角のまま変わりませんでした
(色だけは `Ctrl+Z` で prefix に入った瞬間に反映されます。herdr がそのタイミングでカーソルを
同期しているためです)。多重化器がカーソルを自分で描いている以上、ttyskk 側から操る手段は
ありません。

一方、**文字として書いた色はそのまま届きます**。`cell` / `beside` / `letter` はこの性質を
使っています。

`cell` はカーソルのあるセルを塗るので、**カーソルそのものが色付いたように見えます**。この
ときはカーソルの形を下線に固定します (ブロックだと色を覆ってしまうためです)。つまり
**形 = ttyskk が動いている合図、色 = モード**という配分になります。素の端末ではこれがいちばん
自然に見えます。

多重化器の下で `cell` が見えるかどうかは、**多重化器が描くカーソルの形**で決まります。四角
なら色を覆ってしまうので `beside` か `letter` にしてください。多重化器の側で下線やバーに
できるなら `cell` が使えて、下線と色が同じ場所に重なって見えます。herdr なら次の二行で細い
カーソルになります (全ペイン共通の固定値で、モードには追随しません)。

```toml
# ~/.config/herdr/config.toml
reveal_hidden_cursor_for_cjk_ime = true
cjk_ime_cursor_shape = "underline"
```

`beside` はカーソルの**右隣**を塗ります。多重化器がカーソルの見た目を遅れて同期する環境では
`cell` の色がブロックのカーソルに覆われて見えません (herdr が実際にそうです)。`beside` なら
覆われないので確実に見えます。この方式では**カーソル自体には色を付けません** —— 付けると
色付きのものが二つ並んで紛らわしくなるためです。色は箱が担い、カーソルは形だけで表します。

`off` は多重化器の下では形が届かないので、何も分からなくなります。素の端末なら `cell` が
いちばん自然で、`off` でも形で五つのモードを区別できます。
