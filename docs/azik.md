# AZIK (拡張ローマ字入力)

「2 文字めに《ん》が来る」「二重母音」という、日本語に多い並びを 2 打で打てる入力方式です。
README に基本の表があります。ここでは取り決めの全体と、標準ローマ字との違いを説明します。

```toml
[behavior]
romaji = "azik"    # 既定は "default"
```

## 撥音拡張 (母音 + ん)

母音キーの代わりに、その下のキーを打ちます。

| | あ段 | い段 | う段 | え段 | お段 |
|---|---|---|---|---|---|
| キー | `z` | `k` | `j` | `d` | `l` |
| 例 | `kz` かん | `kk` きん | `kj` くん | `kd` けん | `kl` こん |

あ行には拡張を当てません (`ai` あい、`aq` あん)。あ段の撥音は `n` でも打てます (`sn` さん、
`dn` だん)。

## 二重母音

母音キーの近くのキーを打ちます。

| | あい | うう | えい | おう |
|---|---|---|---|---|
| キー | `q` | `h` | `w` | `p` |
| 例 | `sq` さい | `kh` くう | `sw` せい | `kp` こう |

## そのほかの取り決め

- **「っ」は `;`、長音は `:`、単独の「ん」は `q`** (`nn` も打てます)
- **シャ行は `x`、チャ行は `c`** —— `sh` と `ch` は二重母音の拡張 (`s` + `h` = すう) に使う
  ためです
- **小書きのかなは `l` を前置します** (`la` ぁ、`lyo` ょ、`kulwa` くゎ) —— `x` をシャ行に
  譲ったためです
- 拗音の `y` は `g` でも打てます (`kga` きゃ、`kgp` きょう)。左右の交互打鍵になります
- 同じ指が続く綴りは `f` で打てます (`kf` き、`mf` む)
- 頻出の並びは 2 打です (`kt` こと、`ds` です、`mn` もの、`sr` する)

## 明け渡す綴り

入力方式を足すと、既存の綴りのいくつかは明け渡すことになります。

- `sh` が「すう」になるので、`shi` で「し」は打てません。シャ行の子音は `x` へ移ります
- `ch` も同様で、チャ行は `c` へ移ります
- `x` を明け渡した分、小書きのかなは `l` の前置になります
- **子音の重ねによる促音は使えません** (`tt` は「たち」、`kk` は「きん」)。促音は `;` の一打
  に移ります

「標準ローマ字も打てる」という言い方は、正確には「標準ローマ字の大半は打てる」です。どこを
明け渡したかは上のとおりです。

## 変換表の持ち方 (実装の話)

**変換表は標準ローマ字への展開として持っています。** `kz` → `kann` → 「かん」という組み立て
なので、かなの綴りを二重に持ちません。子音の並びも標準表の見出しから集めるため、標準表に
項目を足せば AZIK の側にも自動で反映されます。

手で書いてあるのは、拡張キーの対応 9 個と、規則から外れる特殊拡張 27 個・互換キー 20 個ほど
だけです。組み合わせには `yi` のようにかなにならないものが混ざりますが、**標準表で最後まで
変換できたかどうか**で振り分けて落としています。
