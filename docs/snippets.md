# 定型文 (スニペット)

住所・電話番号・メールの署名のように「打つのが面倒で、内容が決まっている」文字列を、辞書
とは別に持てます。README の「定型文」に基本の書き方があります。ここでは残りを説明します。

## 編集器から書く

見出し語を先に決めなくてよいので、既にあるものを見ながら足せます。

```sh
ttyskk --edit-snippets            # 一覧を開きます
ttyskk --edit-snippets かいしゃ   # 見出し語を埋めた雛形を足して開きます
```

新しい項目の雛形を末尾に足し、**その行にカーソルを置いて**開くので、書き足す場所を探すところ
から始めなくて済みます。手つかずのまま閉じれば雛形は残りません。変換の途中からなら、候補が
尽きて登録に入ったところで `space` を押しても同じ編集器に行けます。

キーを一つ割り当てれば、変換に入る前からでも編集器を開けます。既定は空です —— ローマ字に
ならない英字は `l` と `q` しかなく、制御キーの空きは環境ごとに違うため、決め打ちしていません。

```toml
[keys]
snippet_edit = "C-t"
```

## 書式

**VS Code のスニペット** (`*.code-snippets`) です。TextMate 由来のこの書式は LSP の仕様にも
入っていて、事実上の共通語になっています。nvim の LuaSnip も `from_vscode` で同じファイルを
読めるので、**編集器と入力メソッドで一つのファイルを分け合えます**。注釈 (`//`) と末尾の
カンマを書いても構いません。

```jsonc
{
    // 会社の連絡先。異動があったらここだけ直します
    "会社住所 (日本語)": {
        "prefix": "かいしゃじゅうしょ",
        "body": ["東京都港区…"],
        "description": "日本語"
    },
    "会社住所 (英語)": {
        "prefix": "かいしゃじゅうしょ",
        "body": "1-2-3 …, Minato-ku, Tokyo",
        "description": "英語"
    },
}
```

`prefix` が見出し語、`body` が候補、`description` が候補の右に出る注釈になります。同じ見出し
語を二つ書けば `space` で選べるので、**日本語版と英語版を並べて注釈で見分けられます**。

## 置き場所

既定は利用者辞書と同じ `~/.local/share/ttyskk/snippets.code-snippets` です。辞書を git に
載せていれば、定型文もそのまま行き来します。学習と分けたい場合や、他の人と分け合いたい場合
は `[snippets]` で移せます。

```toml
[snippets]
files = ["~/.config/ttyskk/work.code-snippets"]
```

編集器で保存した時点で読み直すので、ttyskk を起動し直す必要はありません。

## 日付や時刻

`body` には日付を書いておけます。**候補に出る時点でもう開いている**ので、確定してから気付く
のではなく、選んでいる最中に確かめられます。

```jsonc
"今日の日付": { "prefix": "きょう", "body": "$CURRENT_YEAR-$CURRENT_MONTH-$CURRENT_DATE" },
"日報の見出し": { "prefix": "にっぽう", "body": "## $CURRENT_MONTH/$CURRENT_DATE ($CURRENT_DAY_NAME_SHORT)" },
```

使えるのは `CURRENT_YEAR` `CURRENT_YEAR_SHORT` `CURRENT_MONTH` `CURRENT_MONTH_NAME`
`CURRENT_MONTH_NAME_SHORT` `CURRENT_DATE` `CURRENT_DAY_NAME` `CURRENT_DAY_NAME_SHORT`
`CURRENT_HOUR` `CURRENT_MINUTE` `CURRENT_SECOND` `CURRENT_SECONDS_UNIX` です。月名と曜日名は
英語になります (`July`、`Tue`)。知らない名前はそのまま残るので、`$HOME` のような文字列は
素通りします。

## 穴を埋める

`$1` を書いておくと、確定せずに**一つずつ埋める段**へ移ります。埋め終わってから組み上げて
渡すので、途中の姿は子アプリに見えません (シェルでも編集器でも同じように動きます)。

```jsonc
"挨拶メール": {
    "prefix": "あいさつ",
    "body": ["${1:宛先} 様", "", "いつもお世話になっております。${2:名前} です。", "$0"]
},
"返事": { "prefix": "へんじ", "body": "${1|承知しました,検討します|}。" },
```

| 書き方 | 意味 |
|---|---|
| `$1` `${1}` | 埋める場所 |
| `${1:既定値}` | 既定値つき。そのままでよければ触らず次へ進めます |
| `${1\|日本語,英語\|}` | 選ぶ場所。`space` で回します |
| `$0` | 埋め終わったあとのカーソル位置 |
| `\$` | `$` そのもの |

| キー | 動作 |
|---|---|
| `TAB` | 次の場所へ。最後で押すと組み上げて渡します |
| `Shift+TAB` | 前の場所へ |
| `Enter` | 組み上げて渡します (変換の途中ならその変換を決めます) |
| `C-g` | やめます。何も出さずに消えます |

**埋めながら変換できます。** 打った文字はいまの場所へ溜まり、そこで変換がそのまま使えます。
打ちかけのものは埋める場所へ差し込んで見せるので、全体のどこに入るのかがその場で分かります。

```
[埋め 1/2]▼田中 様、⏎⏎いつもお世話になっております。名前 です。
```

同じ番号を二度書けば、どちらにも同じ値が入ります。`$0` の戻しは左矢印を送る形なので、
**行をまたぐ場合は戻しません** (上の行へ移る動きは編集器ごとに違って当てにできないためです)。
